# 🎮 Event Horizon Protocol 50x

An interactive game developed on Scratch for CS50x (Week 1 Project) by Harvard University.

---

###  Play Online
You can play the game directly in your browser:
 **[Play Event Horizon Protocol 50x on Scratch](https://scratch.mit.edu/projects/1377067086/)**

---

### 🎮 Game Controls
- ⬅️ **Left Arrow:** Moves the ship to the left.
- ➡️ **Right Arrow:** Moves the ship to the right.
- 🚀 **Spacebar:** Fires the laser at the enemy ship.

---

### Project Details
- **Platform:** Scratch
- **Course:** CS50x (Week 1)
- **Features:** Player movement, projectile firing mechanics, custom sprites, enemy interactions, and score tracking.

---

### 📁 Source File
The repository contains the source file (`.sb3`), which can be imported directly into the Scratch editor (online or offline) to view or edit the block code.
